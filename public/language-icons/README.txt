Иконки языков программирования для CodePulse.

Источники:
- Devicons — https://github.com/devicons/devicon (лицензия MIT)
- Simple Icons — https://github.com/simple-icons/simple-icons (иконки CC0, бренды принадлежат правообладателям)

Файлы скачаны с CDN jsDelivr и GitHub (raw) 26.11.2026.
Логотип закрашивается цветом курса через CSS-маску, поэтому сохраняется неоновая стилистика.

Для языков без официального логотипа (SQL, COBOL, Assembly, Visual Basic, Carbon, Roc, Hylo, Unison, Verse, Move, Mojo) используется иконка lucide из данных курса.
